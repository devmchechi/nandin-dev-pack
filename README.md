# Nandin Dev Pack

Official agents for [Nandin](https://vaultdb.ai). No account and no key beyond your own model key.

| Agent           | What it does                                                                     | Status   |
| --------------- | -------------------------------------------------------------------------------- | -------- |
| Chief of Staff         | Your representative on your team: finds who is responsible, asks and assigns with your approval, tracks requests, answers for you | Preview  |
| PR Reviewer     | Reviews a pull request (private repos too) against your rules and posts the review after approval | Preview  |
| AWS Ops Analyst | Investigates failed AWS Batch jobs and CloudWatch alarms from their logs and proposes fixes you approve | Preview |

Each agent's `instructions.md` is yours to edit: it holds your rules, while `skill.md` holds how the agent works.

`examples/my-notes/` is a sample notes folder to try Chief of Staff with.
