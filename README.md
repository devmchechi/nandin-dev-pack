# Nandin Dev Pack

Free, official agents for [Nandin](https://vaultdb.ai). They stay free. No account and no key beyond your own model key.

| Agent           | What it does                                                                     | Status   |
| --------------- | -------------------------------------------------------------------------------- | -------- |
| My Work         | Answers questions about your role, owners, deadlines and processes from your notes | Preview  |
| PR Reviewer     | Reviews a pull request against your rules and posts the review after approval    | Planned  |
| AWS Ops Analyst | Investigates failed jobs and alarms and proposes fixes you approve               | Planned  |

Each agent's `instructions.md` is yours to edit: it holds your rules, while `skill.md` holds how the agent works.

`examples/my-work-notes/` is a sample notes folder to try My Work with.
